# Blipzo App v1.1.0 Release Notes

**Version:** v1.1.0  
**Update Type:** Major Features & UX Redesign  
**Prerequisite:** Upgrade from v1.0.0 (Prototype)

## 📝 Executive Summary
v1.1.0 marks the transition of Blipzo from a prototype to a production-grade financial assistant. This release delivers a robust **Offline-First Architecture**, a complete **Authentication Suite**, and a stunning **Glassmorphic UI** overhaul with fluid animations.

---

## 🏗 New Features (Absent in v1.0.0)

### 1. Robust Offline Capabilities
- **Read-Anywhere**: Complete access to transaction history, summaries, and profile settings without network connectivity (powered by SQLite caching).
- **Smart Blocking**: Write actions (Create/Edit) are intelligently disabled to prevent conflicts, with a custom **Blocking Modal** that animates network status changes.
- **Connectivity Monitoring**: Real-time banners notify users when the app switches between "Synced" and "Cached" modes.

### 2. Advanced Authentication
- **Secure Registration**: Replaced basic signup with a verified **OTP (One-Time Password)** flow to ensure account validity.
- **Account Recovery**: Added a "Forgot Password" workflow via email magic links.
- **Profile Management**: Users can now update their **Name** and **Email** directly within the app.

### 3. Dynamic Currency System
- **Global Selection**: A new settings module allowing selection of any global currency.
- **Instant Context**: Changing currency immediately reformats every price across the app (Lists, Summaries, Inputs) without a reload.

### 4. Enhanced Categories
- **Expanded Lists**: The category selection view now supports larger datasets (showing >10 items) with optimized scrolling.
- **Manage Categories**: Improved UI for adding, deleting, and setting default categories.

---

## 🎨 UI/UX Overhaul: The "Glassmorphic" System

### 1. Advanced Transaction Views
- **Floating Summary Button**: A new, scroll-aware summary card in the "All Transactions" view. It expands to show Income/Expense/Balance stats and collapses into a FAB when scrolling to save screen space.
- **Refined Filters**: Completely redesigned Filter UI featuring:
    - **Date Range Pills**: Intuitive start/end date selectors.
    - **Type Toggles**: Segmented controls for Income/Expense/All.
    - **Smart Dropdowns**: Improved category filtering with modal selection.

### 2. Component Design
- **Glass Transparency**: Lists and cards use `BlurView` to create a translucent, layered depth effect against the dynamic background gradient.
- **Fluid Animations**: 
    - **Blocking Modal**: State changes (Loading -> Success/Error) feature complex spring animations, including a drawing checkmark for success.
    - **Theme Switcher**: Physics-based sliding toggle for System/Light/Dark modes.
- **Form Validation**: Real-time visual feedback on input fields (Email/Password) with improved error iconography.
