# Blipzo App v1.1.0 Release Notes

Version: v1.1.0
Update Type: Major features and UX improvements
Prerequisite: Upgrade from v1.0.0 (prototype)

## Executive Summary
v1.1.0 moves Blipzo from a prototype to a production-ready app. This release
focuses on a more reliable offline experience, a complete authentication suite,
currency selection, and a significant UI refresh with new loading, filtering,
and summary patterns.

---

## Highlights
- Offline-first experience with clearer online-only boundaries and feedback.
- End-to-end authentication with OTP, password reset, and stronger validation.
- New currency settings with local persistence and live formatting updates.
- New blocking modal system for consistent loading, success, and error states.
- Refined transaction views, filters, and category selection behavior.
- New profile modules (details, security, categories, currency) with better UX.

---

## New Features

### Authentication and Security
- OTP-based registration flow with improved input UI and validation.
- Password reset flow with better guidance and email validation.
- Profile updates for name and email, with improved sheet UX.
- Persistent session handling using secure cookie storage.
- Explicit session validity state and rate limiting for auth actions.
- Email service integration for authentication flows.
- Improved cookie parsing and multi-header handling for reliability.

### Offline and Connectivity
- Local caching for read-only access to transactions and summaries.
- Dedicated offline prompts that guide users back online when required.
- Global reconnection status modal and clearer "go online" states.
- Online-only areas are gated (security, profile, and currency settings).
- Offline access blocked for sensitive routes with clear prompts.

### Currency System
- New currency settings section and model.
- Currency selection stored locally for offline continuity.
- Live reformatting across lists, inputs, and summaries.
- Currency settings navigation disabled while offline to prevent conflicts.
- Currency API response handling supports both flat and nested data.

### Transactions and Categories
- "Show more/less" behavior for large category chip sets.
- Amount input improvements: better decimal handling, validation, and haptics.
- Category UI/UX adjustments, including spacing and layout refinements.
- Summary card introduced and refined for the all-transactions view.
- Add-transaction sheet logic refactored with improved input handling.
- Filters support reset and clearer update loading feedback.
- Default time period across sections standardized to one month.

---

## UI and UX Improvements

### Loading and Feedback
- Blocking modal standardizes loading, success, and error states.
- Animated success and error states for long-running actions.
- Loading overlay components used for sync and category loading.
- Sync overlay upgraded to use blocking modal states.

### Navigation and Screens
- Profile screen cleaned up (log out and version hidden in some contexts).
- Filters and sort controls redesigned with better reset handling.
- Theme switcher rebuilt with animated glassmorphic styling.
- Profile navigation reorganized into details, security, categories, currency.

---

## Developer and Platform Changes
- API updates aligned to v1.1 response structures.
- ESLint added and config updated for stricter correctness.
- Authentication cookie handling refactored for reliability.
- React Native animations migrated to Reanimated.
- Dependencies added or updated: `react-native-svg`, `expo-secure-store`.
- App config updated for secure store plugin support.
